## Projects

### 🧠 Machine Learning Classification - Match Outcome Prediction (150k Records)

**Technologies:** Python, scikit-learn, Pandas, NumPy, Matplotlib, Seaborn  
*Academic Project - University of Adelaide, 2025*

Built a binary classification system to predict individual match outcomes in League of Legends using post-game statistics from 150,505 player records across seven relational data tables.

**What I did:**

* Compared four supervised learning models: Logistic Regression, Decision Trees, Random Forests, and Gradient Boosting
* Designed a feature engineering pipeline from scratch, including per-minute rate normalisation, KDA efficiency ratios, and team objective differentials
* Best model (Gradient Boosting) hit 88.6% accuracy and 0.964 ROC-AUC, validated with stratified train-test splits and 5-fold cross-validation
* Ran feature importance analysis across all tree-based models to identify which variables actually drive wins versus which just correlate with winning
* Checked for bias by breaking accuracy out by player rank tier; documented sampling bias, temporal bias, and outcome leakage as limitations
* Outlined deep learning extensions (MLP, LSTM, GNN) for future work
